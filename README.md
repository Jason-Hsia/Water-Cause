# 源析水智 · Water Cause AI

> 将“哪个指标超标”转化为“最可能由什么源、经哪条路径、在何时造成，以及下一步该查哪里”。

[在线体验](https://yuanxi-water-ai.jasonhsia1023.chatgpt.site) · 水质异常成因分析与污染源溯源决策工作台

## 它解决什么问题

水质异常研判往往依赖专家经验与单项指标阈值，面对农业面源、雨污混接、园区排放和水文扰动叠加时，排查范围大、响应慢、解释难复用。

源析水智将监测指标、降雨过程与本地经验规则组织为可解释的事件研判：先发现异常，再给出候选成因、证据、置信度和现场核查建议。它是专家的决策辅助工具，不替代规范监测、现场检查或行政执法证据。

## 当前功能

- 总磷、氨氮、COD 与降雨的 24 小时趋势分析；
- 异常事件识别与候选成因排序；
- 证据链、置信度和下一步采样/巡检建议；
- CSV 本地导入与阈值初筛；
- 事件报告导出、核查状态保存；
- 响应式 Vercel 风格工作台界面。

## 快速开始

这是一个无需后端的静态 MVP。直接打开 `dist/index.html`，或在项目目录启动任意静态文件服务器后访问 `dist` 即可使用。

在页面中点击“CSV 模板”下载样例，再使用“导入 CSV”完成本地分析。数据只在浏览器内处理，不会上传到服务器。

## CSV 数据格式

必填字段：`timestamp, station, tp, nh3n, cod`
可选字段：`rainfall`

```csv
timestamp,station,tp,nh3n,cod,rainfall
2026-09-21 16:00,W07,0.18,0.51,13.2,2
2026-09-21 17:00,W07,0.24,0.55,15.1,14
2026-09-21 18:00,W07,0.38,0.59,21.6,10
```

## 研判逻辑

1. 用参考阈值识别总磷、氨氮、COD 异常；
2. 结合异常的时间形态、降雨窗口和污染物组合形成候选成因；
3. 输出证据、置信度和可执行的采样/巡检建议；
4. 将现场核查结果回写，作为后续本地模型标定的依据。
