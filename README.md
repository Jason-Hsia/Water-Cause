# 源析水智 MVP

面向流域、园区和城市河网的水质异常成因分析与污染源溯源决策工作台。

当前 MVP 包含：

- 总磷、氨氮、COD 与降雨趋势；
- 异常事件列表和候选成因排序；
- 证据链、置信度与现场核查建议；
- CSV 本地导入和异常阈值初筛；
- 事件报告导出与核查状态保存。

CSV 必填字段为 `timestamp, station, tp, nh3n, cod`，可选字段为 `rainfall`。所有导入和分析均在浏览器本地完成。

直接打开 `dist/index.html` 即可使用；若浏览器限制本地脚本，可在项目目录运行静态文件服务器并访问 `dist`。

> 当前候选成因采用可解释规则与演示证据，后续接入真实河网拓扑、水文传播、排污口台账和历史核查标签后再训练本地模型。
